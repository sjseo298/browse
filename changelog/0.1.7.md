Fixes extension discovery, browser launching, and setup guidance for unpacked fork installs.

## Fixes
- Pointed `browse install`, `browse extension`, and MCP `status` advice to `https://github.com/sjseo298/browse/releases/latest` instead of Anomaly's Chrome Web Store listing.
- Replaced `open_default()` (which opened Safari when set as macOS default) with `open_chromium()` to launch Google Chrome or an installed Chromium browser, with explicit instructions that Safari is unsupported.
- Updated `browsers::detect()` and `pair_in_browser()` to detect and open `UNPACKED_EXTENSION_ID` (`afeafocngkodbmaipcngoamamfmekgfo`, derived from `public/manifest.json`'s `key`).
