First `sjseo298/browse` fork distribution built locally and published via GitHub Releases + GitHub Pages.

## Major

### Fork distribution & self-update
Binary tarballs (`macos-arm64`, `macos-x64`, `macos-x64-baseline`) and the unpacked extension zip (`browse-extension-0.1.6.zip`) are published to GitHub Releases, while the channel manifest and install scripts are served from the `gh-pages` branch (`https://sjseo298.github.io/browse/release`), so auto-updates and `install` resolve directly against `sjseo298/browse`.

## Improvements & Fixes
- Added `scripts/dist.ts` for 100% local Rust compilation (macOS + `linux-x64` via `zigbuild`), manifest validation via `decide()`, GitHub Release asset uploads, `gh-pages` deployment, 2-release retention (`prune`), and `--overwrite`.
- Added simultaneous multi-relay support in the extension (`relay-pool.ts`, isolated per-relay storage/tab ownership/group colors, shared `All` lent-tab multiplexing, right-click `contextMenus` per relay, multi-relay UI, and 1-click `#add=` pairing links) plus `--port`/`--label` and `browse set port` in the CLI so local Mac OpenCode and SSH-tunneled devcontainers share one Chrome concurrently.
- Fixed `setup::write_keeping_mode` to fall back to in-place writes when `rename()` fails with `EBUSY`/`EXDEV` on Docker bind-mounted `opencode.jsonc` files inside devcontainers.
- Updated `install` and `install.ps1` to accept absolute `https://` target URLs in channel manifests.
- Pointed `browse install`, `browse extension`, and MCP `status` advice to `https://github.com/sjseo298/browse/releases/latest` instead of Anomaly's Chrome Web Store listing, launching Google Chrome / Chromium (never Safari).
- Updated `browsers::detect()` and `pair_in_browser()` to detect and open `UNPACKED_EXTENSION_ID` (`afeafocngkodbmaipcngoamamfmekgfo`, derived from `public/manifest.json`'s `key`).
- Rebranded user-facing extension, installers, and package scope to `sjseo298` while preserving dual-scope detection for pre-fork installs.
- Synced `upstream/dev` improvements past `v0.1.5`: mute-agent-tabs setting, bounded relay HTTP request body drain, `--help` short-circuit without running commands, space-separated CLI tool option values, and numeric tab IDs passed as strings.
