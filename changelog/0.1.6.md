First `sjseo298/browse` fork distribution built locally and published via GitHub Releases + GitHub Pages.

## Major

### Fork distribution & self-update
Binary tarballs (`macos-arm64`, `macos-x64`, `macos-x64-baseline`) and the unpacked extension zip (`browse-extension-0.1.6.zip`) are published to GitHub Releases, while the channel manifest and install scripts are served from the `gh-pages` branch (`https://sjseo298.github.io/browse/release`), so auto-updates and `install` resolve directly against `sjseo298/browse`.

## Improvements
- Added `scripts/dist.ts` for 100% local Rust compilation, manifest validation via `decide()`, GitHub Release asset uploads, and `gh-pages` deployment.
- Updated `install` and `install.ps1` to accept absolute `https://` target URLs in channel manifests.
- Rebranded user-facing extension, installers, and package scope to `sjseo298` while preserving dual-scope detection for pre-fork installs.
